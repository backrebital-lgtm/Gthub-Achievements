راهنمای فارسی همکاری در GitHub و پیگیری فعالیت‌های واقعی پروژه.

## اجرای محلی

به Node.js نسخهٔ ۲۰ یا بالاتر نیاز دارید؛ نصب وابستگی لازم نیست.

```sh
npm test
npm run check
```

## همکاری ساعتی

گردش‌کار `Hourly maintenance` در دقیقهٔ ۱۷ هر ساعت به وقت UTC، و با اجرای دستی در تب Actions، کار می‌کند:

1. سلامت فایل‌های راهنما و تست‌های برنامه را بررسی می‌کند.
2. Issueها و PRهای باز همین مخزن را می‌خواند.
3. در صورت وجود کار، یک Issue هماهنگی ایجاد یا به‌روزرسانی می‌کند.
4. اگر وضعیت تغییری نکرده باشد، چیزی منتشر نمی‌کند.

این برنامه یک هماهنگ‌کنندهٔ قطعی است؛ عامل هوش مصنوعی برای تولید کد یا مکالمه نیست. کارهای خودکار با هویت `github-actions[bot]` انجام می‌شوند. برنامه PR، تأیید، پاسخ پذیرفته‌شده یا نویسندگی انسانی جعل نمی‌کند و دریافت Achievement را تضمین نمی‌کند.

زمان اجرای GitHub Actions ممکن است تأخیر داشته باشد. زمان‌بندی باید روی شاخهٔ پیش‌فرض باشد و در مخزن عمومی پس از ۶۰ روز بی‌فعالیتی ممکن است غیرفعال شود.
