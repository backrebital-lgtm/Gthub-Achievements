# نشان‌های GitHub

GitHub رویدادهای واجد شرایط را به Achievement تبدیل می‌کند. این قابلیت در public preview است و جزئیات کامل محاسبه منتشر نشده است. تعداد رویدادهای قابل مشاهده، تضمین دریافت نشان نیست.

## هدف‌های عملی

- Pull Shark: PRهایی که خود حساب باز کرده و merge شده‌اند. هدف ابتدایی گزارش‌شده ۲ PR مفید است؛ باز و بسته کردن PR بدون merge کافی نیست.
- Pair Extraordinaire: مشارکت مشترک واقعی در commitهای PR ادغام‌شده. ثبت دو نام برای یک شخص را همکاری دو نفر تلقی نکنید.
- Galaxy Brain: پاسخ درست در Discussions از نوع Q&A که به‌عنوان Answer انتخاب شود. هدف اولیهٔ گزارش‌شده ۲ پاسخ پذیرفته‌شده است؛ پرسش و پاسخ ساختگی را هدف نگذارید.
- Starstruck: توجه واقعی به مخزن ساخته‌شده توسط حساب؛ نقطهٔ شروع گزارش‌شده ۱۶ ستاره است. ستارهٔ حساب دوم به‌تنهایی این هدف را فراهم نمی‌کند.
- Quickdraw و YOLO: به رویدادهای بستن سریع یا merge بدون review مرتبط هستند؛ برنامهٔ نگهداری برای آن‌ها رویداد تولید نمی‌کند.
- Public Sponsor: به حمایت از طریق GitHub Sponsors مربوط است؛ این پروژه هیچ پرداختی انجام نمی‌دهد.

## موارد غیرقطعی یا تاریخی

Heart On Your Sleeve و Open Sourcerer هدف قطعی این پروژه نیستند؛ راه دریافت عمومی و قابل اتکا در منابع رسمی بررسی‌شده تأیید نشده است. ادعای قطعی قبلی دربارهٔ دریافت با یک قلب یا چند مخزن قابل اتکا نبود.

Mars 2020 و Arctic Code Vault به رویدادهای تاریخی مرتبط‌اند؛ با فعالیت جدید نمی‌توان مشارکت در آن رویدادها را بازسازی کرد.
